# ☕ Java & Programação Orientada a Objetos (POO) — Exercícios Acadêmicos

Este repositório reúne os exercícios, projetos práticos e atividades desenvolvidas em Java durante a graduação em **Análise e Desenvolvimento de Sistemas**, focando nos pilares da Programação Orientada a Objetos (POO).

---

## 📂 Estrutura da Pasta `/linguagem orientada a objetos(POO) -JAVA-/`

Aqui estão organizados os projetos e exercícios desenvolvidos na IDE (Apache NetBeans / Eclipse):

| Pasta / Projeto | Descrição / Conceito Aplicado |
| :--- | :--- |
| 📁 **`oo02`** | Modelagem de classes, atributos, métodos e instanciação de objetos (Clientes, Endereços). |
| 📁 **`OO3`** | Aprofundamento em encapsulamento, construtores e métodos getters/setters. |
| 📁 **`faculdade_tecnologia`** | Exercícios práticos e desafios propostos em sala de aula. |
| 📁 **`diversao-java`** | Algoritmos de teste, estruturas de controle e manipulação de lógica em Java. |
| 📁 **`fernando`** | Testes de implementação de classes e regras de negócio individuais. |

---

## 📚 Conceitos & Pilares Praticados

- **Abstração & Encapsulamento:** Mapeamento do mundo real para classes e proteção de atributos (`private`, `public`, `protected`).
- **Herança & Polimorfismo:** Reutilização de código através de superclasses e sobrescrita de métodos (`@Override`).
- **Construtores & Métodos:** Inicialização de objetos e estruturação de comportamentos.
- **Relacionamento entre Objetos:** Associação, agregação e composição entre entidades.

---

## 🚀 Como Executar os Projetos

1. Clone o repositório ou navegue até a pasta desejada.
2. Abra a IDE de sua preferência (**Apache NetBeans**, **Eclipse** ou **VS Code** com suporte a Java).
3. Importe a pasta do projeto correspondente.
4. Execute o arquivo principal que contém o método `public static void main(String[] args)`.
