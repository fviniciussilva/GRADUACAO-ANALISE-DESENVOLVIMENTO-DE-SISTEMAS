## 🛠️ Principais Aprendizados do Semestre
* Entendimento profundo da camada física e lógica do computador (CPU, Registradores e Barramentos).
* Domínio dos fundamentos de Sistemas Operacionais (Escalonamento, Threads e Concorrência).
* Conceitos essenciais de UX/UI aplicados na criação de interfaces intuitivas para o usuário.
