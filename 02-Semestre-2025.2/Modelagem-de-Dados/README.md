# 🗄️ Modelagem de Dados

**Status:** ✅ Concluído (Média: 9,5)

## 📌 O que aprendi nesta disciplina

Conceitos essenciais de arquitetura e estruturação de bancos de dados relacionais:

* **Modelagem Conceitual, Lógica e Física:** Criação de Diagramas Entidade-Relacionamento (DER/MER).
* **Normalização de Dados:** Aplicação das formas normais (1FN, 2FN, 3FN) para evitar redundância e anomalias.
* **Integridade Referencial:** Definição de Chaves Primárias (PK), Chaves Estrangeiras (FK) e restrições.
* **Fundamentos de SQL:** Conceitos iniciais de DDL (Data Definition Language) e DML (Data Manipulation Language).
