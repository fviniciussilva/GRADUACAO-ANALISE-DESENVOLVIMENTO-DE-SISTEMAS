# 🟨 JavaScript — Exercícios & Projetos Académicos

Este repositório reúne as atividades, exercícios de lógica e projetos práticos em JavaScript desenvolvidos durante as aulas da graduação em **Análise e Desenvolvimento de Sistemas**.

---

## 📂 Estrutura da Pasta `/javascript/`

Aqui estão organizados os ficheiros e diretórios com as tarefas e conceitos aplicados em sala de aula:

| Pasta / Ficheiro | Descrição / Conceito Aplicado |
| :--- | :--- |
| 📁 **`HTML5Application`** / **`HTML5Application1`** | Projetos base e aplicações web estruturadas em sala. |
| 📁 **`auladejavascript03`** | Exercícios práticos de fixação e manipulação de scripts. |
| 📁 **`exercicioJS`** | Desafios de lógica de programação e sintaxe da linguagem. |
| 📁 **`jsaluno`** | Atividades de cadastro, entrada/saída de dados e manipulação de variáveis. |
| 📁 **`laço_javascript`** | Aplicação prática de estruturas de repetição (`for`, `while`). |
| 📁 **`tabuada do 9`** / **`tabuada_js`** | Algoritmos para geração dinâmica de tabuadas e laços iterativos. |

---

## 📚 Conceitos Praticados

- **Fundamentos & Sintaxe:** Declaração de variáveis, tipos de dados e operadores.
- **Estruturas Condicionais:** Lógica de tomada de decisão (`if`, `else`, `switch`).
- **Laços de Repetição:** Iterações dinâmicas e automação de cálculos com laços de repetição.
- **Integração Web:** Execução de scripts JavaScript integrados a estruturas HTML.

---

## 🚀 Como Executar os Ficheiros

1. Clona o repositório ou navega até à pasta desejada.
2. Abre o ficheiro `.html` correspondente em qualquer navegador web.
3. Para visualizar a saída de scripts ou mensagens do sistema, utiliza o **Console do Desenvolvedor** do navegador (`F12` ou `Ctrl + Shift + I`).
